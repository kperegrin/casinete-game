# Art credits

The baked tileset (`public/assets/tileset-*.png`) is rendered by `tools/make-tileset.mjs` from these sources:

| Folder | Pack | Author | License |
|---|---|---|---|
| `models/kaykit-furniture` | KayKit — Furniture Bits 1.0 | Kay Lousberg (kaylousberg.com) | CC0 1.0 (see LICENSE.txt) |
| `models/kaykit-city` | KayKit — City Builder Bits 1.0 | Kay Lousberg | CC0 1.0 |
| `models/kaykit-restaurant` | KayKit — Restaurant Bits 1.0 | Kay Lousberg | CC0 1.0 |
| `models/kaykit-halloween` | KayKit — Halloween Bits 1.0 | Kay Lousberg | CC0 1.0 |
| `models/kenney-arena` | Kenney — Mini Arena (tree, statue, trophy…) | Kenney (kenney.nl) | CC0 1.0 |
| `models/kenney-city` | Kenney — Starter Kit City Builder (fountain, grass) | Kenney | MIT (see LICENSE.md) |

Sources: github.com/KayKit-Game-Assets and github.com/KenneyNL. CC0 does not require attribution — this file says thank you anyway.

Everything else is original to Casinete: the procedural models in `bake/scene.js` (TV, arcade, piano, casino tables, buildings,
signs, wallpaper, …), the 3D characters in `public/js/char3d.js`, and the ground/floor textures in `public/js/textures.js`.
Runtime 3D for the characters uses three.js (MIT, `public/vendor/three-LICENSE.txt`).
